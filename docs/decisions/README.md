# Decisions

This directory contains project-wide decisions for SWERIK.

Decision documents do not include a status field. A decision document merged to `dev` is considered accepted and current unless a later decision amends, supersedes, or overturns it.

Drafts, proposals, rejected ideas, and unresolved alternatives should stay in branches, pull requests, issues, or discussion threads rather than being merged here as decision documents.

Do not edit decision documents that have already been merged to `dev`, except for narrow mechanical maintenance such as applying a later accepted decision about the decision-document format. Substantive changes should be recorded in a new decision.
